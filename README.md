# datadog

A [Mythic](https://github.com/its-a-feature/Mythic) C2 Profile that allows agents to perform comand and control (C2) communication via Datadog's case management feature.

## Installation
```
sudo ./mythic-cli install datadog https://github.com/mkuenzie/datadog
```

## Setup

Refer to documentation-c2/datadog/_index.md for detailed instructions on obtaining and configuring a datadog tenant.
